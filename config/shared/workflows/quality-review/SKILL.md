# Qualitätsreview

Read the authorized case, immutable source versions and open measures; use minimum necessary evidence. Propose review points, addendum, owner, pilot or closure criteria. Authorized quality staff reviews conclusions. Record changes append-only, deliver approved measures and monitor aggregate outcomes. Never rewrite original staff evidence or auto-assign blame.
