# Spätdienst Pflege

Read unresolved claimed/role-queued team questions first, then the exact handover and remaining responsibilities. Use current assignments, accepted evidence and delivery receipts. Propose only actual work, explicit deferrals and attributable replies. Staff reviews each material change. Record through the same command path, deliver configured operations, reconcile ambiguous outcomes and transfer every open responsibility with an explicit receiving-shift receipt.
