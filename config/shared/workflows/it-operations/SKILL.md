# IT- und Integrationsbetrieb

Read configured instance health, leased job status, attempts and sanitized errors; use receipt/read-back before retry. Propose safe retry, investigation or vendor escalation. IT reviews controlled resolution. Record technical actions, deliver only through the closed adapter and retain final receipts. No shell, SQL, arbitrary HTTP, clinical sign-off or unrestricted patient/HR/private data access.
