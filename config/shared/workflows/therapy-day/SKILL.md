# Therapietag

Read the therapist's appointments, selected patient/encounter and existing human-approved goals; use relevant changes only. Propose performed intervention, observed outcome, question and follow-up. The treating professional reviews the note. Record accepted evidence, deliver configured documentation and coordinate unresolved issues. Do not infer a treatment plan from model text.
