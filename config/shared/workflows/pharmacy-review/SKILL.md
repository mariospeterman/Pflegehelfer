# Pharmazeutischer Review

Read the authorized current medication sources, versions and addressed discrepancies; use only verified mappings. Propose clarification, attributed pharmacy response or follow-up owner. A pharmacist reviews the result. Record the review separately from the medication order, deliver only verified operations and close or escalate the discrepancy. Never create, change or discontinue medication from generic chat.
