# Reinigungsrunde

Read assigned rooms, work type, approved hygiene precautions and release state; use no unnecessary diagnoses. Propose performed cleaning, material issue, blocked access or room-release request. Staff reviews the completion. Record exact work and deliver task status; escalate unclear precautions to hygiene/care. Never perform staff surveillance or infer infection diagnoses.
