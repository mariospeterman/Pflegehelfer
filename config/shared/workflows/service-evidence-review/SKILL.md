# Leistungsnachweis prüfen

Read accepted work events, assignment/order references and export status; use the approved billing-rule version. Propose missing information, possible duplicate, owner or ready-for-export state. Authorized staff reviews each classification. Record review separately, deliver only the approved export and resolve rejection. Never invent care, duration, tariff or billable activity.
