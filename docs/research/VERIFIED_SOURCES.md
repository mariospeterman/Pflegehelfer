## Dependency record

Exact package pins were checked against npm registry metadata on the access date and are locked in `pnpm-lock.yaml`: React 19.2.8, Vite 8.2.2, Fastify 5.12.3, @fastify/static 10.1.3, Zod 4.5.4, TypeScript 6.0.3, ESLint 9.39.5, Vitest 5.0.0 and Playwright 1.63.0. TypeScript 7.0.2 and ESLint 10.10.0 were current but rejected because the typed ESLint/plugin ecosystem declared incompatible peer ranges. Patch upgrades require the normal verification suite; clinical profiles and model weights never auto-upgrade.
