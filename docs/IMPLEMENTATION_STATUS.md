## Acceptance recovery update — 2026-09-14

- The retired bespoke conversation surface was replaced with the composable
  OpenUI `AgentInterface`. Pflegehelfer supplies one clinical composer, one
  route-owned scroll area, an allowlisted renderer and a server-backed
  `ChatStorage`; OpenUI's browser-memory history and generic cross-patient
  sidebar are not used. General and patient drafts remain separately keyed by
  actor, patient and encounter.
- `/api/v1/assistant/query/stream` now emits the Vercel AI SDK v6 `UIMessage`
  SSE protocol consumed by OpenUI's `vercelAIAdapter`. The response is
  authorized and persisted before stream start. A persistence failure returns
  an error and revokes authority instead of sending a successful stream with a
  late error frame.
- Successful bounded-agent conversation/answer/clarification/no-action paths
  bypass the retired intent-to-fixed-prose switch. The general no-patient chat
  displays the model's actual bounded source-free answer; patient record facts
  remain exact server-rendered atoms bound to authorized tool results. Drafts
  still enter deterministic review and one-use execution authority.
- Live correction state is reconciled with the server's one-use pending
  authority. When a newer revision arrives, every earlier OpenUI approval turns
  into a read-only correction notice immediately; reload reissues only the
  exact current token and never revives a superseded action.

- The integrated profile is running against separate operational PostgreSQL,
  Medplum 5.1.37 and the bearer-protected stateful provider simulator; it has no
  memory-store fallback.
- The current real-store regression is 7 PostgreSQL files/24 tests plus the
  live Medplum optimistic-concurrency test (1/1). Security, operational restore
  checksum and air-gap/preflight checks pass.
- Provider acknowledgement now survives a temporary read-back failure, and a
  terminal delivered row requires complete read-back evidence with matching
  provider versions. Technical transport failures retry; mapping/authentication
  failures remain terminal/manual.
- The bounded agent now chooses authorized read tools or one general typed
  clinical-draft tool directly. No last-tool routing or nested extraction-model
  call remains. Evidence is retained independently of visible cards; plain text
  is the default and optional table/chart OpenUI is hydrated only from an exact
  cited result. Deterministic code rebinds sources, recipients and safety fields;
  restored proposals are revalidated before authority or execution.
- The active natural-response path no longer compares German content words
  with tool or card JSON and never trusts the model's own `conversation` label
  as proof that prose is harmless. The model selects exact run-local scalar
  claims and optional bounded presentation; server code renders clinical fact
  atoms from those claims. Task title/state and measurement
  concept/value/unit/occurrence-time/review-status stay indivisible. Social
  acknowledgements and clarification prompts are server-owned. Each source is
  retained with exact claims, source metadata and a snapshot digest, visible
  even when no card is rendered or after the response is archived. The model
  sees only opaque run-local evidence handles, bounded facts and freshness;
  stable source IDs, versions, hashes and row provenance remain server-side.
  General source-free conversation may retain the model's bounded wording;
  source-free patient claims still fail closed.
- Pending work is suspended across a deliberate patient switch and restored
  only in the same patient/encounter/thread with a fresh one-use token.
- Independent browser-document UUIDs now bind selection, history, pending
  review, voice authority and execution to one tab. Switching the patient in
  one tab invalidates only that tab's stale authority; another authorized tab
  retains its own patient thread.
- Voice review retains the immutable original ASR transcript/hash/model and a
  separately hashed human-reviewed correction through proposal, accepted note,
  conversation record and the Medplum `DocumentReference`; no audio is stored.
- An IT operator can inspect and requeue only the exact blocked clinical
  projection queue head using an error-bound, idempotent command. The retry is
  audited and never skips or marks the projection delivered.
- PostgreSQL interruption acceptance now injects a failure at browser-context
  rebinding after the old episode has been paused and the spontaneous episode
  inserted. The transaction restores the episode, segment, original draft,
  thread/tab context, proposal, authority, receipts, audit/events and delivery
  queues, then accepts and byte-identically replays the same command after the
  failure is removed. Omitted pause text now preserves an existing draft in
  both PostgreSQL and the executable memory test double.
- Integrated browser evidence covers 390 px, tablet and desktop/dark layouts;
  a 150% text and reduced virtual-keyboard viewport case is automated. The
  selected-patient handover acceptance is now placed before expanded details
  and above the composer. The final browser matrix has no overflow, fatal
  state, console error or visible control below 44 px. The separate
  memory-profile E2E regression passes 66
  tests with 19 deliberate project skips; it is not integrated evidence.
- The fresh OpenUI worktree passes 424 enabled unit/integration tests with 25
  environment-gated skips, zero-warning lint, both TypeScript checks, the
  production PWA/API build, security, operations and peer-dependency checks.
  The OpenUI-rich main JavaScript chunk is currently about 2,363 kB minified
  and 688 kB gzip; measured code splitting remains a performance follow-up.
- The hosted synthetic model call reached the configured endpoint but failed
  the complete model contract and reported deterministic fallback. A real

## Current assessment

The running result is the intended conversational clinical coworker, not the retired dashboard. A staff member can receive the complete configured eight-patient handover, explicitly choose context, work through planned or alarm/spontaneous episodes, document several facts naturally, revise and restore one review, reuse approved documentation in the active episode, communicate with the team, defer/resume responsibility, transfer to the next shift and distinguish local acceptance, Medplum storage and provider confirmation. Better models improve language and presentation but cannot replace policy, typed execution, Medplum, adapters, approvals or audit.

It is **not production-ready for real patient data or clinical use**. Remaining internal P1 work includes: migrate the other direct mutation paths; complete workflow/read-set binding; resource-native Medplum reconstruction; append-only handover addenda; relational inbound/conflicts and multi-replica replay; governed pack publication; ACL-enforced shared threads; RLS/least privilege, retention, two-replica and real restore proof; and formal clinical/model evaluation. External gates are institutional identity/device proof, private vendor contracts, accepted Swiss-German model/audio artifacts, deployment approvals and production backup/restore evidence.
