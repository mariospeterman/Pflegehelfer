## Honest production assessment

This repository is now a real, Medplum-integrated, locally runnable product demonstration—not an unrelated mock screen. It proves the intended clinical architecture with realistic fictional Swiss workflows and failure-capable provider contracts. It must not yet be used with real patients: production identity/access policy, validated terminology/model/ASR packs, private vendor contracts, infrastructure assurance and institutional approvals remain evidence-backed gates.
