## Current honest assessment

This branch is a real integrated synthetic showcase, not the retired mock dashboard. It is suitable for product evaluation with fictional data. It is **not production-ready for real patient data**: the operational repository/event-worker architecture, real identity, validated model/ASR/profile packs, least-privilege Medplum configuration and private provider contracts remain open as listed above.
