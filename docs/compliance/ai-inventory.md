# AI inventory

The deterministic clinical core does not require AI. The model-agnostic gateway supports a fast OpenAI-compatible classifier/drafter and a separate deep path over a versioned, role-approved local knowledge corpus. The integrated fictional showcase uses local Ollama when configured and can use a hosted API only with `PFH_DEMO_MODE=true` plus explicit consent and synthetic-only classification. Production local fast/deep/ASR runtimes require separate immutable model digests; redirects and link-local/public endpoint origins are rejected. Output must match the bounded OpenUI component schema, remains assistive, and cannot directly execute writes; one-use opaque intents require the same user, patient, encounter, purpose and resource version plus explicit confirmation. Browser speech is synthetic-only. Selected weights, prompts, Swiss clinical evaluation, hardware, drift monitoring and approval remain deployment gates.
