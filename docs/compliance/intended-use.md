# Intended use

Pflegehelfer is a workflow and documentation assistant for authorised staff in Swiss inpatient rehabilitation and long-term care. It consolidates task, observation, communication, handover, rounds, and intake context; creates human-reviewed drafts; and synchronises approved records through explicit adapters. It supports, but does not replace, professional judgement or authoritative source systems.

The synthetic demo is for engineering and validation only. A production deployment requires institution-approved identity, policies, data processing, terminology, vendor contracts, clinical validation, and governance.
