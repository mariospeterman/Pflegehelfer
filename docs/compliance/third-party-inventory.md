# Third-party inventory

Runtime libraries are Fastify, React, Zod, `@fastify/static`, `@fastify/multipart`, `@medplum/core`, `@medplum/fhirtypes`, and `@openuidev/react-lang`. Build/test tools are TypeScript, Vite, Vitest, ESLint, Prettier, Playwright, concurrently, tsx, and pnpm. The integrated demo embeds self-hosted Medplum 5.1.37, PostgreSQL 16 and Redis 7 through Docker Compose. Production additionally requires governed identity/policy, observability, immutable audit/backup and optional local vLLM/ASR services; Keycloak, OPA and Flowable remain architectural options rather than embedded claims. WiCare, careCoach, SAP, device and nurse-call systems are integration targets only; no undocumented SDK or endpoint is included. Generate and review a lockfile-derived SBOM for every release.
