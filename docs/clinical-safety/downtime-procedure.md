# Downtime procedure

Declare downtime when identity, authoritative clinical data, audit integrity, or required provider availability cannot be trusted. Show read-only/stale state, stop queued writes if reconciliation safety is uncertain, continue institution-approved paper/source-system procedures, and use the primary nurse-call system. Record local identifiers/times without copying data to unapproved tools. On recovery, identify duplicates/conflicts, reconcile against authoritative timestamps/versions, obtain clinical review, then close the incident.
